# In silico identification and metabolic modeling of novel endosymbionts across diverse niches in weevils (Coleoptera: Curculionidae)

Computational decontamination pipeline for identification and analysis of endosymbionts from whole-genome sequencing reads.

## Pipeline

This pipeline analyses the following weevil species:

Cereal and grain feeders (_Sitophilus_ spp.)

- _S. granarius_ (granary weevil)
- _S. oryzae_ (rice weevil)
- _S. zeamais_ (maize weevil)

Acorn and nut borers (_Curculio_ spp.)

- _C. caryae_ (pecan weevil)
- _C. elephas_ (chestnut weevil)
- _C. glandium_ (acorn weevil)

Wood boring bark and ambrosia beetles (_Dendroctonus_ spp., _Ips_ spp., and _Xyleborus_ spp.)

- _D. frontalis_ (southern pine beetle)
- _D. ponderosae_ (mountain pine beetle)
- _D. valens_ (red turpentine beetle)
- _I. typographus_ (European spruce bark beetle)
- _X. affinis_ (sugarcane shot-hole borer)

Other weevils from diverse lineages

- _Anthonomus grandis_ (boll weevil)
- _Diaprepes abbreviatus_ (diaprepes root weevil)
- _Hypothenemus hampei_ (coffee berry borer)
- _Rhynchophorus ferrugineus_ (red palm weevil)
