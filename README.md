# In silico identification and metabolic modeling of novel endosymbionts across diverse niches in weevils (Coleoptera: Curculionidae)

Jason Shang ([jzhoushang@gmail.com](mailto:jzhoushang@gmail.com))

## Pipeline

This pipeline analyses the following weevil species:

- Sitophilus oryzae (rice weevil)
- Sitophilus zeamais (maize weevil)
- Curculio glandium (acorn weevil)
- Curculio caryae (pecan weevil)
- Rhynchophorus ferrugineus (red palm weevil)
- Xyleborus affinis (sugarcane shot-hole borer)
